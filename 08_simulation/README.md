# 08_simulation

The sensitivity of the H1 and H2 tests, on artificial second tasks built from the stop-signal data. Scripts are listed in the order they were run.

1. `simulate_margin.py` (`h1`, the `wb`/`wb` design, `SuccStop_vs_UnsuccStop`, 300 datasets per level)
2. `simulate_margin.py` (`h2`, the `proj`/`asso` design, `SuccStop_vs_UnsuccStop`, 300 datasets per level)
3. `simulate_margin.py` (`h2power`, the `proj`/`asso` design, `SuccStop_vs_UnsuccStop`, 300 datasets per level)
